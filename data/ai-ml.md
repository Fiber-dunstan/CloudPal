# AI and Machine Learning Services on AWS

AWS offers both fully managed AI services requiring no ML expertise, and platforms for building custom models.

## Amazon Bedrock
Bedrock provides API access to foundation models from multiple providers (Anthropic, Meta, Amazon, and others) through a single interface, without managing any infrastructure. It supports fine-tuning, Retrieval-Augmented Generation (RAG) via Knowledge Bases, and agentic workflows.

## Amazon SageMaker
SageMaker is a full platform for building, training, and deploying custom machine learning models — covering data labeling, notebook environments, distributed training, hyperparameter tuning, and managed model hosting endpoints.

## Pre-built AI Services
Amazon Rekognition analyzes images and video for object detection, facial analysis, and content moderation. Amazon Comprehend performs natural language processing tasks like sentiment analysis and entity recognition. Amazon Transcribe and Polly convert speech to text and text to speech, respectively.

## Amazon Q
Amazon Q is AWS's generative AI assistant, available in variants for developers (code suggestions, code transformation) and for business users (querying internal company data conversationally).
