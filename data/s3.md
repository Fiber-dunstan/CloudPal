# Amazon S3 (Simple Storage Service)

Amazon S3 is an object storage service that stores data as objects within buckets, designed for 99.999999999% durability and virtually unlimited scalability.

## Storage Classes
- S3 Standard: frequently accessed data.
- S3 Intelligent-Tiering: automatically moves objects between tiers based on usage.
- S3 Standard-IA / One Zone-IA: cheaper storage for infrequent access.
- S3 Glacier / Glacier Deep Archive: lowest-cost long-term archival, minutes-to-hours retrieval.

## Key Features
Versioning keeps multiple variants of an object. Lifecycle policies automatically transition or expire objects. Bucket and IAM policies control access, and S3 Block Public Access prevents accidental exposure. Server-side encryption (SSE-S3, SSE-KMS) protects data at rest.

## Advanced Capabilities
Presigned URLs grant temporary, time-limited access to a private object without changing bucket permissions. Multipart upload splits large files into parts uploaded in parallel, improving speed and resilience. Cross-Region Replication (CRR) and Same-Region Replication (SRR) automatically copy objects between buckets. Object Lock enforces WORM (write-once-read-many) retention for compliance.

## Common Use Cases
Backup and archival, static website hosting, data lake storage for analytics, and storing application assets like images, logs, and build artifacts.
