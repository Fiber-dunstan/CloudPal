# AWS Well-Architected Framework

The Well-Architected Framework is a set of principles for evaluating and improving cloud architectures, organized into six pillars.

## The Six Pillars
- **Operational Excellence**: run and monitor systems to deliver business value, and continually improve processes.
- **Security**: protect data, systems, and assets through risk assessments and mitigation strategies.
- **Reliability**: ensure a workload performs its intended function correctly and consistently, recovering quickly from failures.
- **Performance Efficiency**: use computing resources efficiently and adapt as demand and technology evolve.
- **Cost Optimization**: avoid unnecessary costs and understand where money is being spent.
- **Sustainability**: minimize the environmental impact of running cloud workloads.

## Using the Framework
AWS provides the Well-Architected Tool (free in the console) to review a workload against these pillars, surfacing risks and recommending remediation steps. It's commonly used before major launches or during periodic architecture reviews.
